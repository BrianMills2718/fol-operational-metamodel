What this project is doing, in pictures

You asked for a type diagram of first-order logic: its parts, which part is a kind of which, and what makes a formula true. This page shows what got built, where it drifted, and a phased way back.

Two terms, with a kitchen example

Patched server

You buy a dishwasher, but its rack won't hold your tall pots. So you bend one wire in your rack. Now your pots fit, but only in your kitchen, and only if that dishwasher is plugged in.

FLAMS is a program a university research group wrote for searching collections of formal math. An agent wrote a small change to FLAMS's code (a 53-line "patch" file) and applied it to our own copy so it would accept files from MMT. A patched server is that changed copy, running on some computer. Right now it isn't running anywhere.

Upstream contribution

You mail your bent-wire idea to the dishwasher maker. If they adopt it, every new dishwasher ships with the taller rack, and nobody has to bend wires again.

For FLAMS, that means sending that change to its authors on GitHub and asking them to include it. That never happened. Until it does, the "live" part of our viewer only works on a machine where someone has rebuilt FLAMS with our change by hand.

What exists today

Each box is a real file or program in the repo. Blue boxes work today on any laptop. Orange dashed boxes are the FLAMS branch, which needs the patched server.

The gap

What you asked for

A picture like a database schema: "Universal quantification is a kind of quantified sentence, which is a kind of sentence", plus what a structure is and when a sentence is true in it.

What the viewer shows

A force-directed tangle: 115 dots pushed apart until they settle, so "is a kind of" lines are buried among "has property" lines. The truth side (structures, satisfaction) isn't in any imported source.
